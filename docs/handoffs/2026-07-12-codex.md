# Codex handoff — sportscardsnearme.ca hardening batch

## Context (read once)
Astro 7 + TypeScript (strictest) + Tailwind v4 static site, live at sportscardsnearme.ca.
573 stores baked from a Google Sheet into `src/data/stores.json` at build time. Interactive
Mapbox GL island (`src/scripts/map-core.ts`, mounted by `src/components/MapIsland.astro`);
readiness handoff via `src/scripts/map-registry.ts` (NEVER CustomEvents — they race Astro's
module script order). 36 unit tests (Vitest, `tests/unit/`), 9 e2e (Playwright, both 375px
and desktop projects). Map markers only render when `PUBLIC_MAPBOX_TOKEN` exists — a local
`.env` has one; NEVER print or commit its value.

## Hard rules
- Branch `codex/hardening` off latest `redesign`. NEVER push or merge to `main` (domain
  deploys run from main only). PR back into `redesign`.
- Before the PR, ALL of: `npm test` && `npx tsc --noEmit -p tsconfig.json` && `npm run build`
  && `npm run test:e2e` — green, no skips beyond the existing 3 token/viewport self-skips.
- TypeScript strict, no `any` (existing sanctioned casts are marked), no `console.log`.
- Do not touch: `.github/workflows/`, `docs/research/`, `public/logos/`, `src/data/*.json`
  (generated), `scripts/bake-stores.ts`, `.env`.
- Client DOM built from data uses createElement/textContent only (XSS discipline; see
  `tests/unit/pins.test.ts` for the enforcement pattern).

## Tasks (independent; commit each separately)
1. **Lazy-load mapbox-gl.** `src/scripts/map-core.ts` statically imports mapbox-gl (~495KB gz)
   on every page. Restructure so the library (and its CSS) load via dynamic `import()` only
   after the token check passes. `mountMap` may become async — `MapIsland.astro`'s script and
   `src/scripts/map-registry.ts` consumers must keep working (registry pattern already handles
   late registration). Acceptance: tokenless build's initial JS excludes mapbox-gl (verify by
   bundle size in `dist/_astro/`); all e2e pass tokenless AND with token.
2. **Logo pin fallback.** `src/scripts/pins.ts` `badgeFor`: if the logo `<img>` errors, swap
   it for the initials span (same as no-logo path). Unit test with happy-dom dispatching an
   `error` event.
3. **Scope the city payload selector.** `src/pages/[province]/[city]/index.astro` script reads
   `document.querySelector('script[data-map-stores]')` — scope it to the island inside
   `[data-city-map]` so a second island on a page can never cross-feed.
4. **Kill the mobile pre-JS layout shift.** Same file: `[data-city-map]` gets `max-md:hidden`
   server-rendered in its class list; delete the JS line that adds it after load.
5. **Tag-filter e2e.** On `/alberta/edmonton/`, click the first `[data-filter-tag]` chip,
   assert `[data-results-count]` decreases or stays (and never errors); toggle off restores.
6. **404 noindex.** Add a `noindex` robots meta to the 404 page only (extend Base.astro with an
   optional `noindex` prop or inline the tag via a named slot — smallest clean change wins).
